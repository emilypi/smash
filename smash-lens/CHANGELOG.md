# Revision history for smash-lens

## 0.2.0 -- 2026-10-26

* Start the `0.2` major release series and require `smash >=0.2.0 && <0.3`.
* Preserve the existing optics API and traversal behavior.

## 0.1.0.4 -- 2026-10-26

* Update dependency bounds and the supported GHC matrix to 9.6–9.14.
* Update copyrights through 2026.
* Add Tasty unit and property tests for constructor selection and traversal laws.

## 0.1.0.3 -- 2022-04-03

* Update `base` bounds to allow GHC 9.2.x

## 0.1.0.2 -- 2022-04-02

* Update `lens` dependency bound to allow for `lens-5.0` and `lens-5.1`

## 0.1.0.1

* Add `Iso`s for `Wedge`, `Can`, and `Smash`. [#14](https://github.com/emilypi/smash/pull/14)

## 0.1.0.0 -- YYYY-mm-dd
