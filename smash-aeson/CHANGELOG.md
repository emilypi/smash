# Revision history for smash-aeson

## 0.2.0.2 -- 2026-10-26

* Update dependency bounds and the supported GHC matrix to 9.6–9.14.
* Update copyrights through 2026.
* Support `aeson >=2.0 && <2.4` while retaining the explicit JSON wire formats.
* Decode two-field objects independently of key order.
* Add fixed wire-format fixtures, malformed-input tests, and ordinary/lifted instance properties.
